# Network Traffic Analysis & Social Engineering Defense

## Project Overview
A cybersecurity practice project focused on network traffic analysis and identifying potential social engineering indicators.

## Tools Used
- Kali Linux
- Wireshark
- SHA-256

## Key Topics
- Network protocol analysis
- DNS query investigation
- Email header analysis
- SPF, DKIM, and DMARC
- Social engineering indicators
- SOC security recommendations

## Project Type
Training / Simulation

## Disclaimer
This project uses practice evidence and does not represent a confirmed security incident.
